
Similarity scoring produces several files, each containing Hindi–Telugu pairs and similarity scores. 
But machine translation models cannot train on multiple scattered files. 
So we built corpus.py, which acts like a ‘corpus aggregator’. 
It reads every file, picks only valid Hindi–Telugu pairs, cleans them, and merges everything into one unified file called corpus.tsv. 
This final corpus becomes the input to our bilingual dictionary, language model, TF-IDF model, and translation systems.”

def clean_text(text):
    text = str(text).strip()
    text = re.sub(r'\s+', ' ', text)
    return text

Converts data to string
Removes leading & trailing spaces
Replaces multiple spaces/newlines with a single space
