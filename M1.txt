//Information extraction 
    Information Extraction (IE) is an NLP task that automatically extracts structured information (like names, places, dates, entities, relationships, etc.) from unstructured text (like documents, reviews, webpages).
    Think of it like this:

    Input: Free-flowing sentence or paragraph
    Output: Structured data (like a table, JSON, etc.)

     Types of Information Extraction Tasks
     1. Named Entity Recognition (NER)
         Extract entities such as: name,locations,organizations,dates,percentages 
     ex: Text: "Apple Inc. was founded by Steve Jobs in Cupertino in 1976."
           Entities:
            ORG: Apple Inc.
            PERSON: Steve Jobs
            GPE: Cupertino
            DATE: 1976
     2. Relation Extraction
         Find relationships between entities.
          ex: Entity 1: "Steve Jobs", Relation: "founded" , Entity 2: "Apple Inc."
     3. Event Extraction
         Identify events and their participants.
         Example: "John signed the contract on Monday."
     4. Slot Filling / Template Filling
          Populate structured templates.
          e.g., For resumes, extract: name, education, skills, experience.
    

    ex: “Dr. A. P. J. Abdul Kalam was born on 15 October 1931 in Rameswaram, India.”  do information extraction
     
     1.  Text Preprocessing
       lowercasing, Sentence splitting, Tokenization, Removing noise (optional)
     2.  Named Entity Recognition (NER)
          A. P. J. Abdul Kalam → PERSON  
            15 October 1931 → DATE  
            Rameswaram → GPE  
            India → GPE
     3. Relation Extraction (Optional) :
          Use a pattern or trained model to extract facts like:
           person:
           date:
           places :

     4. output as structured data :
             {
            "person": "A. P. J. Abdul Kalam",
            "birth_date": "15 October 1931",
            "birth_place": ["Rameswaram", "India"]
           output  }

/Real-world Use Cases of Information Extraction
    Extracting info from resumes, legal documents, emails
    Mining medical reports for patient data
    Analyzing news articles (who did what, when, where)
    Processing customer reviews (product features, sentiment per feature)

    | 2. NER                       | Identify entities (person, date, org, etc.) |

//text summarization 
    Text Summarization is an NLP task where a system automatically creates a shorter version of a text while retaining the main ideas or important information

    Types of Text Summarization
    1. Extractive Summarization
        How it works: Selects important sentences or phrases directly from the original text
        Does not generate new words, just picks key points.
        Example:
            Original: "The cat sat on the mat. It was very fluffy. Dogs were playing outside."
            Summary: "The cat sat on the mat. Dogs were playing outside."
    2. Abstractive Summarization :
        How it works: Generates new sentences to capture the meaning of the text.
        ses deep learning or NLP models to rewrite in a concise way.

            Example:
            Original: "The cat sat on the mat. It was very fluffy. Dogs were playing outside."
            Summary: "A fluffy cat rested on the mat while dogs played outside."

   //steps involved 
    1.text input :
        Raw text is collected (article, report, document).
    2. Text Preprocessing
        Cleaning: remove punctuation, lowercase text, remove stopwords.
        Tokenization: split text into words or sentences.
        Optional: lemmatization/stemming.
    3. Language Understanding (Key Step!)
        Goal: Let the machine “understand” what the text is about.
        methods :
            Extract semantic meaning (what is the topic, entities, relationships).
             Generate contextual embeddings (e.g., using BERT, GPT).
        This step is critical for abstractive summarization because the model needs to grasp meaning, not just pick sentences.
    4. Feature Extraction / Importance Scoring
        For extractive summarization: rank sentences by importance using scores (TF-IDF, TextRank).
        For abstractive summarization: use embeddings to represent meaning and generate new text.
    5. Summary Generation :
        Extractive: pick top-ranked sentences.
        Abstractive: generate concise sentences using deep learning models (T5, BART, GPT). 
    6. Postprocessing
        Fix grammar, punctuation, coherence
        output theh final summary 


//turing test 
   The Turing Test is a test proposed by Alan Turing (1950) to determine whether a machine can exhibit intelligent behavior indistinguishable from a human

   Participants:
      Human evaluator, Human participant, Machine (AI system)
    Setup: 
       The evaluator interacts through text with both the human and the machine.
       This avoids any bias from voice, appearance, or gestures
    Evaluation :
        If the evaluator cannot reliably tell which is the machine, then the machine is considered to have passed the test.

    It measures the appearance of intelligent behavior, not actual human-like thinking.

//summary 
  Machine Translation :
      Machine Translation (MT) is an NLP task where a text written in one language is automatically converted into another language.
       The process begins with text preprocessing, which includes cleaning, tokenization, and normalization. 
       Then, the system either uses pre-trained models or APIs, or you can train your own model using a parallel corpus of source and target language pairs. 
       The model learns the mapping between languages and generates a translation. Finally, postprocessing ensures that the output text is coherent, grammatically correct, and ready for use.
  Information Retrieval :
      Information Retrieval (IR) focuses on extracting relevant information from large amounts of data.
       From an input query or document, techniques such as Named Entity Recognition (NER) and relation extraction are used to identify key entities, relationships, and facts.
        The system returns structured data that can be used for further analysis or downstream NLP tasks. Unlike simple search, IR aims to understand the content to retrieve meaningful information efficiently.
  Question Answering :
       Question Answering (QA) is the task of providing direct answers to user queries. 
       Early systems, like ELIZA, performed QA by pattern matching and returning responses that already existed in a database.
        Modern QA systems can generate answers dynamically using learned knowledge, but the core principle remains: extracting relevant information from text or structured data to respond accurately to questions.
  Dialogue Systems :
       Dialogue Systems, or conversational agents, are designed to interact with humans via text or speech. 
       These systems simulate human-like conversations using techniques like Natural Language Understanding (NLU), dialogue management, and response generation. 
       Examples include virtual assistants like Siri, Alexa, and Google Assistant. Dialogue systems maintain context over multiple turns, understand user intent, and provide appropriate, coherent responses.

 Text-to-Speech (TTS) :
       Text-to-Speech converts written text into spoken words. 
       The process begins with text preprocessing and normalization, which includes tokenization, lemmatization, and expansion of abbreviations (normalization). 
       Then, a TTS engine synthesizes the speech using acoustic and linguistic models. This technology allows machines to speak naturally, enabling applications like voice assistants, reading aids, and automated announcements.
 Speech Recognition :
       Speech Recognition, or Automatic Speech Recognition (ASR), converts spoken language into text.
        The system first removes noise and disturbances, then performs preprocessing and normalization on the captured audio. 
        After processing, the system generates structured textual output that can be further used for analysis, commands, or feeding into other NLP tasks.
 Information Extraction (IE) :
      Information Extraction is closely related to Information Retrieval but focuses on transforming unstructured text or audio data into structured information. 
      Using techniques like Named Entity Recognition, relation extraction, and event detection, IE identifies key elements (names, dates, locations, relationships) from the input. 
      This structured data can then be used for analytics, database population, or feeding other NLP systems.
